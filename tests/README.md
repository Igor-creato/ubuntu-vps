# Тесты для Ubuntu VPS Scripts

## Запуск тестов

### Локальное тестирование ssh-setup.sh

```bash
bash tests/test-ssh-setup.sh
```

**Что проверяется:**
1. ✓ Синтаксис bash скрипта
2. ✓ Правильность определения путей к бинарникам
3. ✓ Использование полного пути `/usr/sbin/ss`
4. ✓ Проверка существования группы `sudo` в функции `ensure_user`
5. ✓ Наличие детального логирования на критических этапах

## Исправленные проблемы

### 1. Ошибка с командой `ss`
**Проблема:** Команда `ss` из пакета `iproute2` не находилась через `$PATH`  
**Решение:** Изменён `SS_BIN` с `ss` на `/usr/sbin/ss` (полный путь)

### 2. Ошибка при повторном запуске с существующим пользователем
**Проблема:** `usermod -aG sudo` падал, если группа `sudo` не существует  
**Решение:** Добавлена проверка существования группы перед добавлением

### 3. Недостаточное логирование
**Проблема:** При ошибке не было ясно, на каком этапе произошёл сбой  
**Решение:** Добавлено детальное логирование на каждом критическом этапе
